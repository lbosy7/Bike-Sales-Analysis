

# Bike Sales Analysis Using Microsoft Excel

## Project Overview

This project focuses on analyzing customer purchasing behavior to understand the factors influencing bicycle purchases.

Using Microsoft Excel, I explored customer demographics, income levels, age groups, commute distances, occupations, and geographical regions to identify patterns and trends associated with bike purchases.

The analysis was conducted using data cleaning, Pivot Tables, and an interactive dashboard to transform raw customer data into meaningful business insights.

## Objectives

The main objectives of this project were to:

- Understand customer purchasing behavior.
- Identify age groups with higher bike purchase rates.
- Analyze the relationship between commute distance and bike purchases.
- Explore purchasing patterns across different geographical regions.
- Examine customer demographics and income levels.
- Present findings through an Excel dashboard.

## Tools and Technologies

- Microsoft Excel
- Pivot Tables
- Data Cleaning
- Data Analysis
- Data Visualization
- Excel Dashboard

## Dataset Description

The dataset contains 1,000 customer records and 14 columns, including:

- Customer ID
- Marital Status
- Gender
- Income
- Number of Children
- Education
- Occupation
- Home Ownership
- Number of Cars
- Commute Distance
- Region
- Age
- Age Brackets
- Purchased Bike

## Data Preparation

The data preparation process involved:

- Creating a working copy of the original dataset.
- Standardizing categorical values such as marital status and gender.
- Creating age brackets to facilitate customer segmentation.
- Preparing the data for Pivot Table analysis.

## Exploratory Data Analysis

I used Pivot Tables to investigate:

- Average income by gender and home ownership.
- Bike purchases by commute distance.
- Bike purchases across different age brackets.
- Bike purchases across individual customer age groups.

## Key Findings

1. **Age:** Middle-aged customers recorded the highest purchase rate at approximately 54.6%.

2. **Commute Distance:** Customers commuting 2–5 miles had the highest purchase rate at approximately 58.6%.

3. **Region:** The Pacific region recorded the highest bike purchase rate at approximately 58.9%.

4. **Marital Status:** Single customers had a higher purchase rate (54.1%) compared to married customers (42.9%).

5. **Customer Purchases:** Out of 1,000 customers, 481 purchased bikes, representing 48.1% of the dataset.

## Dashboard

The project includes an Excel dashboard presenting customer purchasing patterns through visualizations.

## Business Recommendations

- Target middle-aged customers through focused marketing campaigns.
- Develop marketing strategies for customers with shorter and moderate commute distances.
- Investigate opportunities in the Pacific region based on its higher purchase rate.
- Segment marketing campaigns according to customer demographics and purchasing behavior.

## Conclusion

This project strengthened my practical skills in Microsoft Excel, data cleaning, Pivot Table analysis, and data visualization.

It also demonstrated how customer data can be used to identify purchasing patterns and support data-driven business decisions.
